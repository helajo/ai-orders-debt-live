# AI Orders & Debt Map · AI 巨头订单与债务关系图

Live, bilingual relationship graph of orders, investments and debt among the AI giants, rebuilt every 3 hours by
the private `helajo/AI-orders-debt` monitor (SEC EDGAR + news, read by Claude) and published here on GitHub Pages.
This repository holds rendered files only; every push is made by the monitor.

- **Live map / 实时关系图:** https://helajo.github.io/ai-orders-debt-live/ (also `latest.html`)
- **Data / 数据:** `data/graph.json` (current), `data/archive/YYYY-MM-DD.json` (one snapshot per day)
- **A past day / 查看历史某日:** `https://helajo.github.io/ai-orders-debt-live/?snapshot=YYYY-MM-DD`
